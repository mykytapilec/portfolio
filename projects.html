Hvalya (GitHub repository)

Music streaming platform for independent artists with an 80/20 revenue split in the artist's favor. A solo capstone project, designed, built and deployed end to end: a NestJS API with Prisma and PostgreSQL, a Next.js web app, an Expo mobile app and a FastAPI recommendation service. Runs on AWS with Docker Compose and GitHub Actions CI/CD.

  • NestJS
  • Next.js
  • React Native
  • FastAPI
  • PostgreSQL
  • AWS

Task Tracker (GitHub repository)

Task management app built with React and TypeScript. Users register and log in with JWT authentication, create boards, organize tasks in columns with drag and drop, and open a task details view. Responsive interface, deployed on AWS behind Nginx with HTTPS. Built as part of the roadmap.sh Task Tracker project.

  • TypeScript
  • Vite
  • Tailwind CSS
  • Zustand

Task Tracker API (GitHub repository)

Backend REST API for the Task Tracker app. Registration and login with password hashing and JWT, user-specific boards and columns, and full task CRUD with descriptions, story points and subtasks. Request validation with Zod, Docker setup and tests with Vitest.

Weather Web App (GitHub repository)

Weather app built with React, TypeScript and Vite. Search a city to see current conditions, temperature and feels-like, humidity, wind and a multi-day forecast, with loading and error states. The last searched city is restored after a reload. Data comes from the Visual Crossing API. Built as part of the roadmap.sh frontend projects.

  • TypeScript
  • Vite
